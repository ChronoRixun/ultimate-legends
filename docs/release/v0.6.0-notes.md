# Ultimate Legends 0.6.0

## New in beta 3

### A new Support page
The Support page now has four tabs:
- **Help**: the redistributables and the launcher FAQ, as before.
- **Report a problem**: **Copy diagnostics** copies a short summary of your launcher, Windows or Proton, main
  monitor (resolution and display scaling) and game setup (fix versions, display mode) to paste into a bug report.
  The page shows exactly what it copies. It has no user name, no account and no full folder paths: your user folder
  shows as `%USERPROFILE%` and game folders by their name only. **Report a bug** opens the bug report form on GitHub
  in your browser (you need a free GitHub account); paste your diagnostics there. **Logs** opens the folder of the
  launcher's log and, for each installed game, its fix's log, with the file selected, so you can attach it.
- **Known issues**: what we know is not working yet, per game.
- **Community**: the Ultimate Legends Discord (help, co-op partners, news) and the GitHub issues.

Same in Ultimate Legends 0.5.2. Details: `docs/release/v0.5.2-notes.md`.

### Fixed
- Steam Deck / Proton: **Settings > Open log folder** started a second launcher instead of opening the folder.

## New in beta 2

### Marvel: Ultimate Alliance (2006 PC) fixes from 0.5.1
- **No more startup crash at 2560x1440, 4K and other sizes the 2006 game doesn't know (#31).** Choose **Update** on
  the MUA 2006 page to get MUA Classic Fix 0.2.3; then every resolution your primary monitor supports is offered.
  Until then only the game's original sizes are offered, and the page explains why.
- **The right window size with Windows display scaling.** On a scaled main monitor (a 4K screen at 150%) Windowed and
  Borderless were about 1.5x too big and spilled onto a second monitor, and Borderless kept a title bar. **Update**
  to MUA Classic Fix 0.2.4: Windowed is then the size you chose, centred, and Borderless covers exactly the main
  monitor. Until then, Fullscreen shows correctly.
- **"I have a working installation" finishes setting up (#32).** Finish Setup and Verify Files now install or repair
  the compatibility files in your folder and register the game; your game files, mods, saves and settings are kept.
  Choose the folder with `Game.exe` in it.

Details: `docs/release/v0.5.1-notes.md`. Known limit: the MUA 2006 resolution list follows the main monitor at
launcher start; restart the launcher after changing your main monitor.

## New in beta 1

### Your own sidebar icons
Open a game's card menu (right-click, the keyboard menu key, or **Y** on a controller) and choose **Change icon...**.
Pick a PNG, JPEG or WebP picture, check the square preview and choose **Use artwork**. The sidebar shows your icon from
then on, including after a restart. **Reset icon** puts back the original icon and keeps your card and banner art;
**Reset artwork** resets all of that game's custom pictures.

Like card and banner art, icons stay on your PC: nothing is uploaded or shared.

### Known issues in beta 1
- Picking a picture through the file dialog under Proton (Steam Deck / Linux) is not verified yet.

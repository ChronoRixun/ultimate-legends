Ultimate Legends 0.5.1 fixes three Marvel: Ultimate Alliance (2006 PC) problems: the game crashing at startup at
resolutions it doesn't know (such as 2560x1440 or 4K), the game window coming out too big with Windows display
scaling, and **I have a working installation** never finishing. Choose **Update** on the MUA 2006 page to get
**MUA Classic Fix 0.2.4**, which carries the in-game parts.

Portable build: unzip anywhere and run `ultimate-legends.exe`, or let 0.5.0 update itself. No game files are
included; every game runs from your own copy. SHA-256 in `SHA256SUMS.txt`. Full list of changes: `CHANGELOG.md`.

### MUA 2006 crashed at startup at 2560x1440, 4K and other sizes (#31)
- **What was broken.** The launcher offered every resolution your monitor reports, but the 2006 game only knows 14
  of them (640x480 up to 1920x1200, plus 2048x1536). With any other size saved (3840x2160, 2560x1440, 2560x1080,
  even 1600x900) the original game read past the end of its own list and crashed a few seconds after start. It
  was never about 4K being too much for the game.
- **What changed.** **MUA Classic Fix 0.2.3** fixes this inside the game (its `dinput8.dll` 0.1.2; `Game.exe` stays
  unchanged). Choose **Update** on the MUA 2006 page (or **Verify Files**) to get it. With it, the launcher offers
  every resolution your primary monitor supports and tells dgVoodoo2 about the size you pick, so the game can open
  its display at it. Tested at 2560x1440, 2560x1080, 1600x900, 1920x1080 and, on a 4K monitor, 3840x2160 into the
  first level.
- **Until you have MUA Classic Fix 0.2.3** the launcher offers only the game's original sizes and says why. If a
  bigger size was saved earlier, the page shows it, explains it, and asks you to pick another before **Play**;
  nothing is changed without you. **Borderless** stretches 1920x1080 or 1920x1200 to a bigger screen.
- Steam Deck / Proton: unchanged; Proton still handles the display mode there.

### MUA 2006's window was too big with display scaling, and Borderless kept its title bar
- **What was broken.** With Windows display scaling above 100% on the main monitor (a 4K screen at the default 150%,
  for example), **Windowed** and **Borderless** came out about 1.5x too big and spilled onto a second monitor, at
  any resolution. **Borderless** also kept a title bar. This was not new in 0.5.1: the 2006 game doesn't support
  display scaling, so Windows enlarged a window that was already the right size.
- **What changed.** **MUA Classic Fix 0.2.4** (choose **Update** on the MUA 2006 page) makes the game handle scaling
  itself: **Windowed** is the size you chose in real pixels, centred on the main monitor, and **Borderless** has no
  frame and covers exactly the main monitor. At 100% scaling nothing changes. Tested on a 4K main monitor at 150%
  with a 1440p second monitor: Windowed, Borderless and Fullscreen at 1920x1080, 2560x1440 and 3840x2160.
- **Until you have 0.2.4**, **Fullscreen** shows correctly, or set Windows' compatibility option for `Game.exe`
  (Properties -> Compatibility -> Change high DPI settings -> Override high DPI scaling behavior: Application).

### "I have a working installation" never finished setting up (#32)
- **What was broken.** Choosing **I have a working installation** for MUA 2006 saved the folder, but **Finish
  Setup** (and **Verify Files**) ran a generic updater that did nothing for this game and still reported success.
  The game's compatibility files were never installed, so the game stayed "not installed" however often you tried.
- **What changed.** A folder that already has MUA Classic Fix is ready straight away. Otherwise **Finish Setup**
  installs the missing compatibility files (MUA Classic Fix, SafeDiscLoader2 and, on Windows, dgVoodoo2) into your
  folder, from the same checked package as a disc setup, and then registers the game. **Verify Files** repairs a
  missing or damaged compatibility file the same way. Your game files, mods, saves and settings are kept, and no
  disc is needed.
- **Which folder to choose.** The one with `Game.exe`, `libIGCore.dll`, `libIGGfx.dll`, `build.ini` and
  `data\herostat.engb` in it, not its parent or its `data` folder; the launcher tells you if you picked the wrong
  one. The folder doesn't need anything from an earlier launcher setup or the disc. The 2016 Steam release (`Marvel.exe`) is the separate Marvel: Ultimate Alliance entry.

### Known limitations
- A size dgVoodoo2 can't show on the monitor it uses still fails with "Display failed!" (for example 3840x2160 on a
  1440p primary monitor). The launcher only offers your primary monitor's own sizes, so this only happens with a
  size saved by hand or from another PC; pick a listed size.
- The resolution list is read from the main monitor when the launcher starts. After you change which monitor is
  your main one (or its resolution), restart the launcher to see that monitor's sizes.
- **Windowed** at your monitor's full size is taller than the screen by the title bar; use **Borderless** for that.
- Everything else from the 0.5.0 known limitations still applies (`docs/release/v0.5.0-notes.md`).

Ultimate Legends 0.5.0 — optional character models for X-Men Legends, made on your PC from games you own.

### New in beta 5
- **Marvel: Ultimate Alliance (2006 PC) is supported.** Its page has an options section: display mode,
  resolution, frame rate limit, VSync, Xbox controller support, mouse capture, Run in background, OpenSpy online
  and the graphics watermark. Every option works with the mouse, keyboard or a controller. Settings are written
  one at a time and keep the rest of the game's configuration; they can't be changed while the game runs.
- **Automatic MUA 2006 setup from your own disc.** Choose **Set up**, pick your retail PC DVD ISO or extracted
  DVD folder and a new or empty game folder. The launcher downloads the checked MUA Classic Fix setup package
  and the original dgVoodoo2 archive (by Dege, pinned by SHA-256), then imports and verifies your game files
  locally without running the original installer. The package includes a source-built SafeDiscLoader2 (by
  nckstwrt). Game.exe stays unchanged. A cancelled or failed setup is never registered; only a completed setup
  is registered as ready to play.

### Known issues in beta 5
- **Cancelling MUA 2006 setup on a slow drive can leave a `.muac-stage-…` folder** inside the chosen game folder
  if cleanup takes longer than 15 seconds. Nothing is registered and the game folder is otherwise unchanged; you
  can delete that folder by hand. A later beta will finish the cleanup itself.
- **Automatic MUA 2006 setup does not work under Proton / Steam Deck yet.** It stops with "Linked folders are
  not supported for setup." The X-Men Legends features are not affected.

### New in beta 4
- **Classic conversation box (XML1 look)** is an optional appearance choice for X-Men Legends. It starts off.
  With Legends Classic builder 0.6.0-beta.2 or newer installed, turn it on and rebuild to use the blue background
  from your own XML1 source. Turn it off and rebuild to restore the PC look. The option stays hidden with older
  builders; the companion builder release is separate.
- Setup also accepts an extracted XML1 install folder. You still need your own X-Men Legends II for PC install.
- Cancelling Rebuild before it changes a finished build keeps the game ready. An interrupted build still offers Resume.
- Building into another folder keeps the original folder's XML2 Fix release record. An incompatible fix has an
  **Install the XML2 Fix** recovery button, and the wizard clearly says a builder update installs when you build.
- Save-import previews are present for testing; installing imported saves and Undo remain disabled while acceptance
  checks are pending. The launcher does not enable player save writes in this beta.

### Fixed (new in beta 3)
- **First X-Men Legends builds work in a new folder on Beta.** The launcher installs the XML2 Fix from your update
  channel before the builder starts and checks it meets that builder's needs. Resume and Rebuild do the same.
  If a download fails or is cancelled, no partial fix is left behind; the build waits until a suitable fix is there.
- **Changing update channel takes effect without a restart.** The X-Men Legends page, setup wizard and Character
  models section refresh their builder/tool answers as soon as you switch. Every build checks the builder again,
  so choosing Beta no longer starts with an old Stable builder and asks you to build a second time.
- **Drop-downs open on Steam Deck / Linux.** Under Proton, clicking a drop-down showed nothing, so Settings > Update
  channel could only be changed blind with the keyboard. Every drop-down (language, theme, update channel, the
  Display rows, the costume choosers) is now drawn inside the launcher's page and opens with the mouse, touch, the
  keyboard or a controller: Enter / A opens it, Up / Down move, Enter / A picks, Escape / B closes it unchanged. On
  Windows they look and work the same, and your settings are kept.

### Character models (X-Men Legends)
- A **Character models** section on the X-Men Legends page: **Off** (the original models), **Community pack**
  (community-made skins, credited to their authors; needs nothing else), **Upgraded** (per hero the best of Marvel:
  Ultimate Alliance 2, Marvel: Ultimate Alliance and the community pack; needs one of those games set up in the
  launcher) and, under More, **Sharpened classic** and **XML2 look**.
- Per hero: where the model comes from and why, a **costume chooser** where a source has several (named costumes and
  who made them; a preview once a community skin is downloaded), and its status: planned, converting, built, or kept
  the original (with the reason).
- **Apply** converts the models on your PC and writes them into the game's `mods` folder (your other mods stay;
  restart the game to see them). **Remove** / **Off** takes them out again. Opening the page checks them, and offers
  **Rebuild** when X-Men Legends was rebuilt since they were made.
- **The launcher never ships a model.** The legends-models tool reads your own installs; community skins are downloaded
  from their author's own links, and each file is checked against its SHA-256. Before the first one, the section shows
  BaconWizard17's terms (don't share the files outside marvelmods.com, don't sell them, credit him); nothing is
  downloaded until you agree. His credits stay with the models.
- **The tool installs like the builder.** The first time, the section offers **Install** (from the tool's GitHub
  releases); later, **Update** when your update channel has a newer one. On the Beta channel you get its test
  versions too.
- With `-offline`, nothing is downloaded: heroes whose community skin isn't on your PC yet use their next source or
  the original model, and the section says so.
- **The Downloads tab shows the character models' work** (new in beta 2): Apply, Rebuild, Remove and the tool's
  install or update each appear there while they run, with what they are doing (downloading a skin, converting hero
  3 of 15, installing), the skins downloaded (file, size, source, SHA-256) and **Cancel**. Finished work, patch
  updates included, stays under **Recent** with how it ended and why.

### Known limitations
- Converting takes a while: about half a minute per hero from Marvel: Ultimate Alliance, several minutes for some
  Marvel: Ultimate Alliance 2 heroes. The game must be closed while the models change.
- Some costume names are still shown by number ("MUA1 costume 0801") where they haven't been named yet.
- Steam Deck / Linux: the launcher runs under Proton / Wine; there is no native Linux build.

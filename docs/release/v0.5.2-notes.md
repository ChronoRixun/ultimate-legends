Ultimate Legends 0.5.2 gives the Support page a proper home for getting help: copy a diagnostics summary for a bug
report, open the bug report form, find the logs, read the known issues and join the community.

Portable build: unzip anywhere and run `ultimate-legends.exe`, or let 0.5.0 / 0.5.1 update itself. No game files are
included; every game runs from your own copy. SHA-256 in `SHA256SUMS.txt`. Full list of changes: `CHANGELOG.md`.

### A new Support page
The Support page now has four tabs. Every tab and button works with the mouse, the keyboard and a controller, in
English, French and Spanish.
- **Help**: the redistributables and the launcher FAQ, as before.
- **Report a problem**:
  - **Copy diagnostics** copies a short plain-text summary to paste into a bug report: the launcher version and
    update channel, Windows' build (or Proton / Wine), your main monitor's desktop resolution and Windows display
    scaling (also while a game runs fullscreen at another resolution, which it then shows as "currently"), and for
    each game whether it is set up, its fix and version (XML2 Fix, MUA Classic Fix, MUA Controller Fix, the
    Legends Classic build) and its display mode. The page shows exactly what it copies, before and after.
  - **Report a bug** opens the bug report form on GitHub in your browser (you need a free GitHub account). Paste
    your diagnostics into it; nothing is filled in or sent for you.
  - **Logs** opens the folder of each log with the file selected, so you can attach it: the launcher's log, its
    update log and, for each installed game, its fix's log (`muac-fix.log`, `xml2-fix.log`,
    `mua-controller-fix.log`) and the Legends Classic builder's log. A log that isn't there yet is greyed out.
- **Known issues**: what we know is not working yet, per game.
- **Community**: the Ultimate Legends Discord (help with setup, co-op partners, news) and the GitHub issues.

### Your privacy
The diagnostics are read on your PC and only go where you paste them. They have no user name, no account and no
full folder paths: your user folder shows as `%USERPROFILE%`, a Linux home folder as `%HOME%`, the computer name
is left out, and game folders are shown by their name only. Logs can contain folder paths: check a log before you
attach it.

### Fixed
- Steam Deck / Proton: **Settings > Open log folder** started a second launcher (which then said Ultimate Legends is
  already running) instead of opening the folder. It opens the folder now.

### Known limitations
- Under Proton (Steam Deck, Linux), **Logs** and **Open log folder** open the folder in Wine's own file browser
  window, not your Linux file manager. Tested under GE-Proton on Linux, not yet on a real Steam Deck. The page
  lists each log's file name, so you can also find it yourself.
- Everything from the 0.5.1 known limitations still applies (`docs/release/v0.5.1-notes.md`).

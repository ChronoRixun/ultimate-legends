Ultimate Legends 0.4.0 — online play for X-Men Legends, controller navigation, and an update channel for testers.

**Online play is in beta for now.** It needs Legends Classic 0.3.0 and **XML2 Fix 1.8.0**, which come out as test
versions first. To try it: Settings → Updates → **Update channel: Beta**, then Verify Files and Rebuild on the X-Men
Legends page. On Stable, the Online section says so and opens that setting for you. Once Legends Classic 0.3.0 is
final, Stable gets it too and the Beta channel isn't needed. Play, LAN and Connect by IP work as before with any
version, on either channel.

### Update channel (new)
- Settings → Updates → **Update channel**: **Stable** (the default) or **Beta**. Beta gets test versions of the
  launcher, the XML2 Fix and the Legends Classic builder early; they may have bugs. Switch back to Stable any time.
- Settings lists the exact versions you have, with a **Beta** badge on a test version.
- Switching back to Stable while on a beta asks first ("You're on a beta (…). Switch back to …?"): **Switch back**
  reinstalls the stable versions and offers to rebuild X-Men Legends; **Keep the beta** changes nothing. Nothing is
  ever downgraded without asking.
- Every download is checked as before (SHA256SUMS.txt for the launcher, the release manifests' hashes for the fix and
  the builder).

### Online play (X-Men Legends)
- **Host a game / Join a game** on the port's page: no port forwarding, no ini editing. The host opens Play Online in
  the game and gets a code like `ABCD-EFGH` (copied to the clipboard by itself); friends paste it and press Join, then
  pick Play Online → Join Game in the game.
- **Browse games**: public rooms of everyone with the launcher, with their level, players and In progress; Join on a
  row. Public games connect players directly, so they can see each other's internet address — share a private code to
  play only with friends.
- Joining a campaign already in progress: wait on the game's Joined Game screen; you come in at the next level change,
  and the party needs enough heroes for everyone.
- Every error in plain words, including "That game can't take new players right now. Try again in a moment." (a room
  that exists but isn't taking players) as distinct from "The game is full".
- A start that is refused or fails leaves nothing behind in `xml2-fix.ini`: a later start from Steam or the exe never
  opens a room. Close launcher after game launch applies to Play only; Host and Join keep the launcher open.

### Controller and keyboard navigation (across the whole launcher)
- A Steam Deck's D-pad and buttons, or any Xbox-style pad, drive every page: arrows move, A presses, B goes back,
  LB / RB switch pages; popups keep the focus; one visible focus ring. (Developed as "0.3.3"; it ships first in 0.4.0.)

### Known limitations
- Until Legends Classic 0.3.0 and XML2 Fix 1.8.0 are final, online play needs the Beta update channel.
- Recovering from an abrupt connection loss and host migration are not part of this release.
- Steam Deck / Linux: the launcher runs under Proton / Wine; there is no native Linux build.

Portable build: unzip anywhere and run `ultimate-legends.exe`. No game files are included; every game runs from your
own install. SHA-256 in `SHA256SUMS.txt`. Full list of changes: `CHANGELOG.md`.

Welcome to Ultimate Legends
Welcome to Ultimate Legends, a community launcher for Marvel: Ultimate Alliance and X-Men Legends on PC. Point it at the games you already have installed and it keeps them patched and ready to play. Head to the Library to set up a game, or the Support tab if you need a hand.
Ultimate Legends is an unofficial fan project. It is not affiliated with or endorsed by Activision, Marvel or Disney, and it never downloads the games: you need your own copies. Based on the CB Servers launcher.

Settings
Launcher preferences.

Appearance

Choose the interface language used by the launcher.
Switch between the launcher's available color themes.
When enabled, the launcher disables its animations and transitions.
Shows games you have not installed in black and white in the library. Turn off to keep their artwork in color.

Launcher

Keeps a Desktop and Start Menu shortcut for the launcher.
When enabled, the launcher will automatically close after launching a game.

Startup

When enabled, the launcher starts without going online: no patch updates or downloads. Same as the -offline flag. Takes effect the next time the launcher starts.
Keeps launcher data and settings in an ultimate-legends folder next to the launcher exe instead of AppData. Same as the -portable flag. Switching moves your data to the new location and restarts the launcher.
Flags the launcher accepts when started from a shortcut or terminal.
-launch <game>Launch a game on startup (mua, mua2, xml2, or any library id)
-install <game>Open the setup flow for a game on startup
-offlineStart without network features (no patch updates or downloads)
-portableKeep data and settings next to the launcher exe

Advanced

When enabled, patch updates will be skipped on launch. Useful when troubleshooting, but you may run an outdated patch.
When enabled, the launcher will not check for missing redistributables before launching a game. Games may fail to start if required components are missing.

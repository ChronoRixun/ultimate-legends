# Ultimate Legends 0.7.0-beta.1 preparation

Optional Remastered controls on the X-Men Legends and X-Men Legends II pages:
master switch, anti-aliasing, anisotropy, optional filtering of point-sampled world
art and centered Beenox menus. Requires XML2 Fix 1.12.0 or later. Changes apply
on the next game start; opening the page writes nothing. Off retains the selected
component settings, and unrelated INI settings/comments are preserved. Edits are
unavailable while a builder owns the folder. HUD/dialogue scaling and render
resolution scaling are not added. No D3D wrapper is bundled.

X-Men Legends page redesign (decided 2026-11-11): a compact 150px banner on every
game page; on the X-Men Legends page Play, the test-mode badge and an attention
strip (not set up, building with progress and Cancel, damaged with Repair, needs
the fix, unfinished) stay above six tabs: Overview, Online, Display & options,
Characters, Mods and Build & tools. Tabs that would be empty are hidden (before a
first build only Overview and Build & tools). Overview opens first, then the last
tab picked, remembered across restarts; a build, damage or an unfinished build
opens Build & tools once. Remastered, Discord and the Classic conversation box are
in Display & options; Test mode is folded under Build & tools "For testers" and
opens by itself when a switch is on; Build & tools also says which update channel
the builder and XML2 Fix follow. Keyboard: Ctrl+PageUp / Ctrl+PageDown step tabs;
pad: LT / RT (LB / RB still change sidebar page).

Optional Vulkan renderer (DXVK), off by default, on the X-Men Legends and X-Men
Legends II pages: turning it on asks first, then downloads DXVK 3.1.1 from its
official GitHub release (doitsujin/dxvk), checks the archive's pinned SHA-256 and
the SHA-256 of its 32-bit d3d8.dll and d3d9.dll, and puts only those two files next
to the game. Turning it off removes exactly those files; a d3d8.dll or d3d9.dll that
is not the pinned one is never replaced or removed. The checked download is kept,
so a rebuild of the X-Men Legends port (which sweeps extra files) puts DXVK back
without downloading again. Under Proton the game already uses Proton's own DXVK,
so the option stays off there.

Prepared on a local branch only. Actual CEF, controller and Proton acceptance
remain separate from native and small-DOM unit tests. No release/tag is created.
